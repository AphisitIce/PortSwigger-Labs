# Server-Side Request Forgery (SSRF)

## Overview

Server-Side Request Forgery (SSRF) is a web security vulnerability that allows an attacker to manipulate a server into making unintended requests to internal or external resources.

Through PortSwigger Web Security Academy labs, I am learning how SSRF vulnerabilities occur, their impact on application security, and the techniques used to identify and prevent them.

## Topics Covered

- Basic SSRF Attacks
- Accessing Internal Resources
- SSRF Against Backend Systems
- Cloud Metadata Exploitation
- URL Validation Bypass
- SSRF Filter Bypass Techniques
- Blind SSRF
- Secure Server-Side Request Handling

## Key Learning Areas

- Server-side request processing
- Internal network exposure risks
- URL validation concepts
- Backend service interactions
- SSRF detection methodologies
- Security controls and mitigations

## Tools Used

- Burp Suite
- PortSwigger Web Security Academy
- Browser Developer Tools

## Learning Objective

Develop a strong understanding of Server-Side Request Forgery vulnerabilities, learn how insecure server-side requests can expose internal resources, and understand best practices for implementing secure request handling mechanisms.
