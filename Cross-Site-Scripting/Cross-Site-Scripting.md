# Cross-Site Scripting (XSS)

## Overview

Cross-Site Scripting (XSS) is a web security vulnerability that allows malicious scripts to be executed in a victim's browser. Through PortSwigger Web Security Academy labs, I am learning how XSS vulnerabilities occur, their impact on users, and how secure web applications can prevent them.

## Topics Covered

- Reflected XSS
- Stored XSS
- DOM-based XSS
- XSS in HTML Context
- XSS in Attributes
- XSS Filter Bypass
- Client-Side Script Injection

## Key Learning Areas

- User input handling
- Output encoding
- DOM manipulation risks
- Client-side security concepts
- Browser execution behavior
- Secure development practices

## Tools Used

- Burp Suite
- PortSwigger Web Security Academy
- Browser Developer Tools

## Learning Objective

Develop a strong understanding of Cross-Site Scripting vulnerabilities and learn how secure coding practices can prevent unauthorized script execution in web applications.
