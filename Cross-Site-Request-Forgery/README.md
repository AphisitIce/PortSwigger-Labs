# Cross-Site Request Forgery (CSRF)

## Overview

Cross-Site Request Forgery (CSRF) is a web security vulnerability that tricks an authenticated user into performing unintended actions on a web application.

Through PortSwigger Web Security Academy labs, I am learning how CSRF vulnerabilities occur, their impact on user accounts, and the security controls that can prevent unauthorized requests.

## Topics Covered

- Basic CSRF Attacks
- CSRF Token Validation
- SameSite Cookie Protection
- Referer-Based Defenses
- Origin-Based Defenses
- Bypassing CSRF Protections
- User Session Exploitation
- Secure Request Validation

## Key Learning Areas

- Session-based authentication risks
- Cross-site request mechanisms
- CSRF token implementation
- Browser security controls
- Request validation techniques
- Secure application design

## Tools Used

- Burp Suite
- PortSwigger Web Security Academy
- Browser Developer Tools

## Learning Objective

Develop a strong understanding of Cross-Site Request Forgery vulnerabilities, learn how attackers exploit authenticated sessions, and understand best practices for implementing effective CSRF protections.
