# SQL Injection

## Overview

SQL Injection is one of the most common web application vulnerabilities. Through PortSwigger Web Security Academy labs, I am learning how SQL injection works, how it can impact web applications, and how secure coding practices help prevent it.

## Topics Covered

- Hidden Data Retrieval
- Authentication Bypass
- Database Version Enumeration
- Database Content Enumeration
- UNION-based SQL Injection
- Blind SQL Injection

## Key Learning Areas

- SQL query structure
- Input validation weaknesses
- Authentication bypass concepts
- Database enumeration techniques
- Secure coding practices
- Risk assessment and mitigation

## Tools Used

- Burp Suite
- PortSwigger Web Security Academy

## Learning Objective

Build a strong foundation in web application security by understanding how SQL Injection vulnerabilities occur and how they can be prevented.
