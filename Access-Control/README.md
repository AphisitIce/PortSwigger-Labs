# Access Control

## Overview

Access Control is a security mechanism that determines which resources and actions a user is permitted to access within an application.

Through PortSwigger Web Security Academy labs, I am learning how access control vulnerabilities occur, their impact on security, and how proper authorization controls protect sensitive functionality and data.

## Topics Covered

- Vertical Privilege Escalation
- Horizontal Privilege Escalation
- Role-Based Access Control (RBAC)
- Insecure Direct Object References (IDOR)
- Forced Browsing
- Unauthorized Function Access
- Parameter-Based Access Control Flaws
- Access Control Misconfigurations

## Key Learning Areas

- Authorization principles
- User role management
- Privilege escalation concepts
- Resource access validation
- Secure application design
- Access control testing methodologies

## Tools Used

- Burp Suite
- PortSwigger Web Security Academy
- Browser Developer Tools

## Learning Objective

Develop a strong understanding of access control mechanisms, identify common authorization weaknesses, and learn best practices for securing sensitive resources and functionality.
